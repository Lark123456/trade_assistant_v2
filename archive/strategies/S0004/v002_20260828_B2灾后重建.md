## 逻辑说明书

【策略定位】B2 高爆发增强形态之二：灾后重建
【核心逻辑】放量上涨使黄白线金叉后，B1 缩量回踩黄线（大哥线≈主力持仓成本），今日 B2 放量长阳拉起：既确认 B1，又确认黄线支撑，是连续拉升前最后震仓的启动点。
【条件】在 B2 七条核心条件之上叠加：
  1. 30 个交易日内出现过白线上穿黄线的金叉
  2. B1（昨天）收盘价 ≥ B1 当天黄线的 99.5%（回踩大哥线）
  3. 回调区 5 日均量 < 金叉当天 5 日均量 × 75%（震仓缩量）
【可调参数】金叉回溯 30 天、回踩容差 0.995、量缩比例 0.75

## 公式原文

```
{ —— 通用前提 —— }
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
{ —— KDJ(9,3,3) —— }
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
昨天B1:=REF(J,1)<13;
{ —— B2 基础达标（七条核心条件） —— }
基础达标:=趋势好 AND 昨天B1 AND J>REF(J,1) AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1) AND J<55 AND J>13 AND C>黄线;
{ —— 30 日内有黄白线金叉 —— }
金叉:=CROSS(白线,黄线);
金叉存在:=EXIST(金叉,30);
金叉日:=BARSLAST(金叉);
{ —— B1（昨天）回踩黄线：收盘 ≥ 当日黄线的 99.5% —— }
昨天黄线:=REF(黄线,1);
回踩黄线:=REF(C,1)/昨天黄线>=0.995;
{ —— 震仓缩量：回调区5日均量 < 金叉时5日均量×75% —— }
建波均量:=REF(MA(V,5),金叉日);
回调区均量:=MA(V,5);
缩量达标:=回调区均量<建波均量*0.75;
{ —— 信号输出 —— }
B2灾后重建:基础达标 AND 金叉存在 AND 回踩黄线 AND 缩量达标;
```
