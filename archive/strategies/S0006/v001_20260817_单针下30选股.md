## 逻辑说明书

【策略定位】单针下30 指标转选股（默认信号，阈值可自行修改）
【核心逻辑】长期资金力度仍强（长期线 > 70），而短期力度急跌至超卖（短期线 < 30）：强势股洗盘末端，等待修复。
【指标定义（与通达信副图完全一致）】
  短期线(N1=3) = 100*(C-LLV(L,N1))/(HHV(C,N1)-LLV(L,N1))
  中期线(N=10) = 100*(C-LLV(L,10))/(HHV(C,10)-LLV(L,10))
  中长期线(N=20) = 100*(C-LLV(L,20))/(HHV(C,20)-LLV(L,20))
  长期线(N2=21) = 100*(C-LLV(L,N2))/(HHV(C,N2)-LLV(L,N2))
【默认选股信号】长期 > 70 且 短期 < 30
【额外买点标记（通达信原公式自带）】
  四线归零买：短期/中期/中长期/长期均 <= 6
  白线下20买：短期 <= 20 且 长期 >= 60
  白穿红线买：短期上穿长期 且 长期 < 20
  白穿黄线买：短期上穿中期 且 中期 < 30
【使用建议】默认信号常与 B1 海选叠加观察；如需改用四线归零买等信号，把公式最后一行替换即可。

## 公式原文

```
{ —— 与通达信副图完全一致的资金线计算，带分母保护 —— }
N1:=3;
N2:=21;
D1:=HHV(C,N1)-LLV(L,N1);
D2:=HHV(C,N2)-LLV(L,N2);
D10:=HHV(C,10)-LLV(L,10);
D20:=HHV(C,20)-LLV(L,20);
短期:=100*(C-LLV(L,N1))/MAX(D1,0.0001);
中期:=100*(C-LLV(L,10))/MAX(D10,0.0001);
中长期:=100*(C-LLV(L,20))/MAX(D20,0.0001);
长期:=100*(C-LLV(L,N2))/MAX(D2,0.0001);
{ —— 通达信原公式自带的四个买点标记 —— }
四线归零买:=IF(短期<=6 AND 中期<=6 AND 中长期<=6 AND 长期<=6,-30,0);
白线下20买:=IF(短期<=20 AND 长期>=60,-30,0);
白穿红线买:=IF(CROSS(短期,长期) AND 长期<20,-30,0);
白穿黄线买:=IF(CROSS(短期,中期) AND 中期<30,-30,0);
{ —— 参考线：85 / 30 —— }
参考线85:=85;
参考线30:=30;
{ —— 默认选股信号：长期>70 且 短期<30（阈值可改） —— }
单针下30信号:长期>70 AND 短期<30;
```
