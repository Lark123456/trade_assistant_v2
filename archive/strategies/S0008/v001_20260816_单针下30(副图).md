## 逻辑说明书

【类型】副图指标
【短期线(N1=3)】3 日随机力度（0-100），白线，看短期超卖
【中期线(N=10)】10 日随机力度（0-100），黄线
【中长期线(N=20)】20 日随机力度（0-100），洋红线
【长期线(N2=21)】21 日随机力度（0-100），红线加粗
【参考线】85、30
【买点标记】四线归零买 / 白线下20买 / 白穿红线买 / 白穿黄线买
【用法】观察洗盘是否到位；转换为选股策略时的默认信号：长期 > 70 且 短期 < 30（阈值可改）。

## 公式原文

```
{ —— 与通达信副图完全一致的资金线计算，带分母保护 —— }
N1:=3;
N2:=21;
D1:=HHV(C,N1)-LLV(L,N1);
D2:=HHV(C,N2)-LLV(L,N2);
D10:=HHV(C,10)-LLV(L,10);
D20:=HHV(C,20)-LLV(L,20);
短期:100*(C-LLV(L,N1))/MAX(D1,0.0001);
中期:=100*(C-LLV(L,10))/MAX(D10,0.0001);
中长期:=100*(C-LLV(L,20))/MAX(D20,0.0001);
长期:100*(C-LLV(L,N2))/MAX(D2,0.0001);
{ —— 通达信原公式自带的四个买点标记 —— }
四线归零买:IF(短期<=6 AND 中期<=6 AND 中长期<=6 AND 长期<=6,-30,0);
白线下20买:IF(短期<=20 AND 长期>=60,-30,0);
白穿红线买:IF(CROSS(短期,长期) AND 长期<20,-30,0);
白穿黄线买:IF(CROSS(短期,中期) AND 中期<30,-30,0);
{ —— 参考线：85 / 30 —— }
参考线85:85;
参考线30:30;
```
