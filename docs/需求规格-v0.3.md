## 一、定位（一句话）

围绕**个人交易策略**的完整闭环系统：**盘前批量筛票 → 盘中重点范围自动扫描 + 观察池跟踪 + 提醒 → 盘后记录与复盘**。

## 二、一天怎么用（用户旅程）

| 时段 | 系统做什么 | 用户做什么 |
|------|-----------|-----------|
| **盘前** | 全市场批量深度扫描（收盘数据 + 完整日K指标判定），输出命中列表 | 查看命中列表 → 一键加入观察池（待审核） |
| **盘中** | 每 1~5 分钟自动扫描**重点范围**（实时行情预过滤后的涨幅/成交额前列 + 观察池）；观察池实时跟踪；条件触发**提醒**（桌面弹窗+声音+**微信推送**） | 看提醒 → 审核新进票、看K线 → 执行操作时记录交易 |
| **盘后** | 全市场批量深度扫描（当日收盘数据）；生成"当日总结"（新信号、触发提醒、观察池表现） | 审核进池票（确认/驳回/补理由）；记录操作与想法；事后评估 |

## 三、模块与要点

### 1. 策略引擎（心脏）
- **策略定义双通道**：
  - 通达信公式：`CROSS(MA(C,5),MA(C,10)) AND V>REF(V,1)*1.5`（现有解析器，持续增强）
  - 可视化条件：字段（价格/涨幅/成交量/指标值…）+ 运算符 + 阈值，多条条件支持 **AND/OR 括号分组嵌套**
  - 两种方式等价，可互相转换
- 每个策略可配置：名称、启用/停用、**扫描节奏**（盘中重点范围 / 盘前盘后全市场 / 仅手动）

### 2. 全市场扫描
- **盘前/盘后**：全市场批量深度扫描（约 5500 只，完整日K + 指标判定），并行多连接 + 日K本地缓存，结果持久化
- **盘中**：自动持续扫描**重点范围**（实时行情预过滤：涨幅榜/成交额榜前列 + 观察池内股票），1~5 分钟一轮
- 新命中 → 提醒 + 自动进入观察池"待审核"状态

### 3. 观察池（自动进池 + 人工审核）
- 状态机：`待审核 → 观察中 → 已开仓 → 已清仓`
- 每条记录：入选理由、触发指标/公式、当时价格、因子快照（技术指标 + 大盘点位）
- 审核操作：确认（补理由）／驳回（留档或删除）

### 4. 盘中提醒
- 条件：价格 / 涨跌幅 / 成交量 / 指标金叉死叉 / **自定义公式**
- 渠道：**桌面弹窗 + 声音 + 微信推送（Server酱/Bark，可配置开关）** + 提醒日志；冷却防重复

### 5. 决策日记（记录为主）
- 交易记录以"**想法与理由**"为核心：为什么开仓/止盈/止损/减仓、触发条件描述、当时的因子快照、事后评估心得
- 盈亏统计：**轻量可选**（简单汇总，不做重持仓管理）

### 6. 复盘
- 当日新信号列表、提醒日志、观察池各票表现、命中历史（哪只票何时命中过什么策略）

## 四、技术底座（已就绪，沿用）

- **数据**：pytdx 直连行情服务器（21台池化自动切换）实时行情/日K；akshare 全市场股票列表
- **存储**：SQLite（观察池/交易日志/因子快照/提醒/扫描历史）
- **界面**：PyQt5 桌面应用，后台线程网络隔离
- **公式**：通达信风格解析器（已支持 20+ 函数，可继续增强）

## 五、已确认的关键决策

| 决策点 | 结论 |
|--------|------|
| 盘中扫描节奏 | 只扫**重点范围**（涨幅/成交额榜前列 + 观察池），1~5 分钟一轮；全市场深度扫放在盘前/盘后 |
| 提醒渠道 | 桌面弹窗+声音 + **微信推送**（Server酱/Bark，可配置） |
| 可视化条件 | 支持 **AND/OR 括号分组嵌套** |
| 盈亏统计 | **轻量可选**（默认记录以想法/理由为核心） |
| 观察池 | 策略命中**自动进池（待审核）**，人工审核确认/驳回 |
| 策略表达 | 公式 + 可视化条件**双通道**，可互相转换 |
