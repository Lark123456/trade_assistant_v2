- 类型：通达信公式

## 逻辑说明书

【策略定位】砖型图超短线（1-4 天快进快出）
【核心逻辑】砖型图数值由跌转升的「翻红」第一天介入，捕捉短期趋势反转的小爆发。
【条件】
  1. 大前提：白线 > 黄线（主力护盘区域，按你的要求已叠加）
  2. 砖型图翻红首日：今天砖型图 > 昨天砖型图，且昨天未翻红
【说明】原版通达信公式 + 白线>黄线过滤；若要纯原版，删除公式中「趋势好」即可。

## 公式原文

```
{ —— 大前提：白线 > 黄线（已按需求叠加） —— }
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
{ —— 砖型图原版算法 —— }
VAR1A:=(HHV(H,4)-C)/(HHV(H,4)-LLV(L,4))*100-90;
VAR2A:=SMA(VAR1A,4,1)+100;
VAR3A:=(C-LLV(L,4))/(HHV(H,4)-LLV(L,4))*100;
VAR4A:=SMA(VAR3A,6,1);
VAR5A:=SMA(VAR4A,6,1)+100;
VAR6A:=VAR5A-VAR2A;
砖型图:=IF(VAR6A>4,VAR6A-4,0);
{ —— 翻红首日：今天转升且昨天未转升 —— }
AA:=REF(砖型图,1)<砖型图;
CC:=REF(AA,1)=0 AND AA=1;
{ —— 信号输出 —— }
砖型图翻红:趋势好 AND CC>0;
```
