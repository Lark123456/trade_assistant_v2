## 一、策略管理在系统里的位置

```
盘前批量筛票 ──► 盘中重点扫描 ──► 盘后记录与复盘
      ▲                ▲                ▲
      │                │                │
   ┌──┴────────────────┴────────────────┴──┐
   │             策略管理（本页）             │
   │  策略 = 你的交易想法 → 机器可执行规则     │
   └───────────────────────────────────────┘
```

**一句话定义**：策略管理是「把你的交易想法，变成**可执行、可验证、可评估**的机器规则」的资产管理系统。它是整个闭环的"发动机"，扫描中心只是它的执行器。

## 二、现有功能清单（v0.6 实况）

### 2.1 数据模型（strategies 表）

| 字段 | 含义 |
|------|------|
| `kind` | formula 通达信公式 / visual 可视化条件 / indicator 指标存档 |
| `formula` | 通达信公式文本（visual 也有，由条件树自动生成） |
| `conditions` | 可视化条件树 JSON（仅 visual 有） |
| `description` | 中文逻辑说明书（保险机制，人工编写） |
| `enabled` | 启停 |
| `scan_mode` | batch 盘前盘后全市场 / intraday 盘中重点 / manual 仅手动 |

### 2.2 界面功能（strategy_tab.py，两个列表）

**策略列表**（formula + visual，参与扫描）：
- 新增 / 编辑 / 删除 / 启用停用 / 立即扫描所选
- 📦 内置库一键导入（按名字去重）
- 📖 说明书（意图说明 + 公式逐条中文释义 + 公式原文）
- 🔍 单票诊断（保险机制第二层）
- 编辑对话框内：公式实时中文释义预览、可视化条件树 + 公式预览

**指标库列表**（indicator 存档，不参与扫描）：
- 查看说明书 / 编辑公式 / 删除
- ⚙ 转换为策略（预填公式 + 信号模板行）

### 2.3 配套能力

| 模块 | 作用 |
|------|------|
| `cond_builder.py` | 可视化条件树：4 个行情字段 + 12 个指标字段，AND/OR 嵌套，4 种比较符；可求值、可导出为公式 |
| `formula_explain.py` | 公式 → 中文逐条释义（自动） |
| `strategy_presets.py` | 6 个内置策略（B1海选/B2普通/B2平行重炮/B2灾后重建/砖型图翻红/单针下30选股）+ 4 个内置指标，均带说明书 |
| `scanner.py` | 消费端：visual 转公式后统一按公式扫描 |
| `scan_center.py` | 消费端：按 scan_mode 批量跑启用策略，命中历史按策略筛选 |
| `diagnose_dialog.py` | 消费端：单票条件级诊断（最新一根K线） |

### 2.4 保险机制现状（验证域）

1. 第一层：说明书（人工意图）+ 自动中文释义（代码 ↔ 本意核对）
2. 第二层：单票条件级诊断（逐条件数值/通过/不通过）
3. 第三层：K线信号回放（T001，**未做**）

## 三、与真实需求的错位分析（问题清单）

> 这是本次梳理的核心产出。按"是否真需要"逐条分析。

### P1. 三条策略表达路径并存，可能有冗余 ✅ 已拍板：移除

> **2026-08-15 拍板结果**：用户确认"策略都是先想好再开发的，不需要图形化拼条件"，
> 可视化条件编辑器已随 v0.6.3 移除（UI + cond_builder 模块 + 相关测试删除，
> 存量 visual 策略自动迁移为 formula）。本条目保留作历史记录。

| 路径 | 表达能力 | 适合谁 |
|------|---------|--------|
| 通达信公式 | 强（REF/序列/形态/多输出） | 你（所有内置策略都是公式） |
| ~~可视化条件~~ | ~~弱：仅 16 个字段 + 4 种比较符，无 REF、无序列、无形态~~ | ~~不写代码的人做简单过滤~~ |
| 指标 → 转策略 | 公式的子集 | 指标复用场景 |

**原分析**：可视化条件能做的一切（价格/涨幅/量/指标阈值过滤），用公式一行就能写；
而你的真实策略（B1/B2/砖型图）全是公式。可视化条件当时没有任何真实使用场景，
但它占了编辑对话框一半的复杂度（双编辑区 + 条件树控件 + 序列化）。
**结论**：确认移除，编辑对话框已简化（策略类型只剩「公式 / 指标存档」）。

### P2. 指标库目前是"半成品"，没有消费端 ⚠

指标（indicator 类型）不参与扫描，K线叠加（T005）**还没做**。
所以现在指标库里的东西**只能看说明书、转策略，画不出来、扫不了**。

**建议**：二选一，不要悬着：
- 短期内先让指标能画（T005 优先级提升），指标库才名副其实；
- 或者指标库暂收进内置库对话框（不占主界面空间），等 T005 落地再放出来。

### P3. 参数写死在公式里，没有"参数化模板" —— 最大的功能缺口 🔴

现状：单针下30 的阈值 70/30、B2 的涨幅 4%、J 值 13/55、砖型图翻红……
全部硬编码在公式文本里。说明书里写着"可调参数"，但**调参数 = 复制公式改一行**。

这是与真实需求错位最严重的一点：交易策略天然是"一套逻辑 + 几组参数"，
通达信本身也是参数面板（N/M/T）。现在的实现把"策略"和"参数"焊死了。

**建议**（新功能，高优先）：
- 策略模板 + 参数表：`参数:N:=14;` 之类的声明语法（或可视化参数表格）
- 编辑对话框加"参数"区：改阈值不碰公式
- 诊断/回放时显示当前参数值

### P4. 策略没有"效果评估"—— 框架上最大的空白 🔴

现状：策略命中 → 自动进观察池 → 你手动看 → 交易记录。但**系统从不告诉你
"这个策略命中后到底涨没涨"**。命中历史只有"当时的价格/涨幅"，没有"N 日后的结果"。

对个人交易决策辅助系统来说，策略管理不该只管理"规则"，还要管理"规则的效果"。
否则策略越来越多（内置 6 个 + 自定义），你根本不知道哪些值得留。

**建议**（新功能，高优先；与 T006 回测是同一件事的两半）：
- 第一步（轻）：命中走势跟踪——命中 N 日后涨跌幅统计，命中历史表直接显示
- 第二步（重）：T006 历史回测——胜率/盈亏/最大回撤

### P5. 没有版本历史 —— 保险机制缺了"时间维度" ✅ 已解决（v0.6.5）

改公式前没留底，说明书和公式可能漂移（改公式时不强制更新说明书）。

**已实施（v0.6.5）**：策略固定编号（S0001...，改名不变、删除不回收）+ `strategy_versions`
版本表（公式/说明书变更自动生成新版本）+ `archive/strategies/{编号}/` 文件夹归档 +
策略管理页"📜 版本历史"（查看任意版本、双版本并排对比）。
存档文件随版本自动写入，删除策略不删归档。

### P6. 扫描节奏与策略焊死 —— 同一策略只能一种节奏

一个策略只能选 batch / intraday / manual 之一。但真实需求可能是：
"B2 既想盘前全市场扫，也想盘中重点范围扫"。节奏本质是**执行配置**，不是策略属性。

**建议**（低优先）：要么支持多节奏，要么节奏改成"执行方案"对象（一组策略 + 节奏 + 候选范围）。

### P7. 小问题集（低优先，先记着）

- 策略列表无分组/标签/搜索（内置库有 category 概念，用户策略没有）——策略多了之后会难受
- 内置库导入按"名字"去重，改名后可重复导入
- manual 节奏的策略没有"一键全跑"按钮，只能逐个点
- 诊断器只看最新一根 K 线（T001 回放后缓解）

## 四、建议框架：策略管理 = 5 个能力域

| 能力域 | 内容 | 现状 | 优先级 |
|--------|------|------|--------|
| **① 资产定义** | 策略的表达（公式为主）、参数化模板 | 公式✅；可视化已移除（P1）；**参数化缺失（P3）** | 🔴 高 |
| **② 生命周期** | 增删改启停、节奏、内置库导入、分组/搜索 | CRUD✅、导入✅；版本缺失（P5）；节奏焊死（P6） | 🟡 中 |
| **③ 验证（保险机制）** | 说明书、自动释义、单票诊断、K线回放 | 前两层✅；回放（T001）未做 | 🟡 中（T001 已在列） |
| **④ 执行** | 扫描节奏分发、结果分级标注 | ✅（B2"完美/稍欠"是很好的先例） | 🟢 已够 |
| **⑤ 效果** | 命中走势跟踪、历史回测、策略对比 | **基本空白（P4）** | 🔴 高 |

**框架结论**：
- 策略管理的本质是**资产（策略）的"定义 → 验证 → 执行 → 评估"闭环**，现状只有前半段（定义/验证/执行），**评估段（⑤）整段空白**，参数化（①内部）也是硬缺口。
- 已砍：可视化条件（P1，v0.6.3 移除）。待拍板：指标库主界面入口（P2）。
- 其余都是增强，按优先级排进 todo 即可。
