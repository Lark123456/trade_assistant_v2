## 逻辑说明书

【策略定位】B1 买点海选器（左侧试仓候选池，不确定性最高）
【核心逻辑】在主力护盘区域内（白线 > 黄线），KDJ 的 J 值跌破 13，短期情绪极度低迷，是洗盘末端的候选区域。
【机器条件】
  1. 大前提：白线 > 黄线（主力短期操盘价在底仓成本之上）
  2. KDJ 的 J 值 < 13（KDJ 参数 9,3,3）
【重要认知】B1 只是海选候选：只有下一个交易日出现 B2（放量长阳），才能反推「昨天就是 B1」。
【人工精选清单（代码不判定，请肉眼过滤）】
  - 之前有过自底部的放量/堆量起涨结构（建仓痕迹）
  - 随后缩量回调，未破起涨最低点
  - 当前位于回调的缩量低位区域
【可调参数】J 阈值 13；白线 = EMA(EMA(C,10),10)；黄线 = (MA14+MA28+MA57+MA114)/4

## 公式原文

```
{ 大前提：白线在黄线之上（主力操盘价在底仓成本之上）}
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
{ KDJ(9,3,3)，与通达信计算一致 }
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
{ B1 海选：J 值跌破 13 }
B1海选:趋势好 AND J<13;
```
