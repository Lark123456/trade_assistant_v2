- 类型：通达信公式

## 逻辑说明书

【策略定位】B2 高爆发增强形态之一：平行重炮
【核心逻辑】主力在同一箱体位置（平行）多次放量买筹，今天的 B2 是其中一炮；主力花了钱就要办事，后续易快速拉升。
【条件】在 B2 七条核心条件之上叠加：
  1. 60 天内至少 2 根「涨幅>4% 且放量」的阳线（含今天）
  2. 这些重炮阳线的收盘价极差 < 10%（同一箱体/平行）
【实现说明】采用通达信近似实现（60 日重炮收盘价最高-最低极差法），非逐根回溯定位；如需更高精度可在结果中肉眼复核。
【可调参数】回溯 60 天、平行容忍度 10%、重炮标准与 B2 一致（涨幅>4% 且放量）

## 公式原文

```
{ —— 通用前提 —— }
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
{ —— KDJ(9,3,3) —— }
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
昨天B1:=REF(J,1)<13;
{ —— B2 基础达标（七条核心条件） —— }
基础达标:=趋势好 AND 昨天B1 AND J>REF(J,1) AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1) AND J<55 AND J>13 AND C>黄线;
{ —— 平行重炮：60 天内 ≥2 根放量长阳，收盘价极差 <10% —— }
重炮阳线:=(C>O) AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1);
炮收:=IF(重炮阳线,C,0);
炮高:=HHV(炮收,60);
炮低:=IF(炮高>0,LLV(IF(炮收>0,炮收,99999),60),99999);
炮次数:=COUNT(重炮阳线,60);
炮间距小:=(炮高-炮低)/炮低<0.1;
{ —— 信号输出 —— }
B2平行重炮:基础达标 AND 炮次数>=2 AND 炮间距小;
```
