# 数据源与复权策略（v0.7.0）

> ## ⚠️ 高优先级硬性要求（后续 Agent 开发必读）
>
> **全系统日K数据必须使用「前复权」口径**（`bars_adjust=qfq`，v0.7.0 起为默认）。
> 原因：用户设计 B1/B2 等策略时基于通达信**前复权**视图（黄白线、KDJ、回踩位置等形态认知
> 均来自前复权形态）；本系统 v0.7.0 之前使用 pytdx **不复权**原始数据，导致跨除权股票
> （尤其每年 6~7 月分红季）的系统判定与用户预期不一致。
> 任何新增功能若涉及日K/指标/形态计算，**必须默认使用前复权数据**，不得回退不复权。
> 实时行情（最新价）不受影响：前复权最新价 = 实际最新价，两者天然一致。

---

## 一、现状与历史

| 版本 | 数据口径 | 说明 |
|------|---------|------|
| ≤ v0.6.x | **不复权**（pytdx 原始） | B1/B2 等策略与全部指标在原始数据上计算，跨除权股票形态失真（遗留问题） |
| v0.7.0 起 | **前复权**（pytdx 自算） | 全量切换；`database._migrate()` 首次切换时清空旧日K缓存，`settings.bars_adjust='qfq'` |

历史 `scan_history` 记录保留不动（旧口径），新扫描全部走前复权。

## 二、数据链路

```
pytdx get_security_bars（不复权日K）  ─┐
                                      ├─→ core/adjust.py 前复权因子 ─→ 前复权日K
pytdx get_xdxr_info（除权除息事件）   ─┘        （SQLite xdxr_events 表缓存）
```

- `DataFeed.get_daily_bars(..., adjust="qfq")` 默认返回前复权；`adjust="none"` 可取原始数据（诊断用）
- 除权事件缓存：`xdxr_events` 表（按股票覆盖式缓存，增量拉取）
- 服务器不支持 `get_xdxr_info` 时：降级返回不复权数据 + `last_adjust="none"` 标记（UI/日志提示），不静默出错

## 三、复权算法（core/adjust.py）

- 黄线/白线无关；仅处理 `category==1`（除权除息）且有实际除权动作的事件
- **pytdx xdxr 数值口径（已实测验证，勿改）**：
  - `fenhong` 每10股现金红利（元），÷10 得每股
  - `songzhuangu` 每10股送转股数，÷10 得每股
  - `peigu` 每10股配股数，÷10 得每股
  - `peigujia` 配股价（元/股），**不除**
- 除权参考价：`ref = (pre_close − fenhong + peigujia×peigu) / (1 + songzhuangu + peigu)`
- 除权日当天原始价已是除权后价格，后复权因子从最早事件起累乘 **1/rate**
  （**除以** rate，不是乘以——乘反会导致复权后除权日跳空，这是 v0.7.0 开发中踩过的坑）
- 前复权 = 后复权整体缩放使最新收盘 == 原始最新收盘
- 成交量/成交额不做复权（与通达信/akshare 惯例一致）
- 事件日无K线（停牌）时 rate 从其后第一个交易日应用

## 四、准确性监测（三层，固化在 test_adjust.py）

| 层级 | 方法 | 容差 |
|------|------|------|
| 1 | 除权参考价 vs 除权日实际开盘价（1~5% 偏差为市场高开/低开，属正常） | >5% 告警 |
| 2 | 复权后除权日相邻交易日无跳空（连续性） | <5% |
| 3 | 最新价锚定：前复权最新收盘 == 原始最新收盘 | <1e-6 |
| 4 | **外部对照**：与 akshare 腾讯源 qfq 抽样逐日对比（归一化） | max 误差 <1% |

akshare 仅用于**离线验证**（`python test_adjust.py`），不参与生产取数（限流风险）。
验证样本：昂利康（送转+派息混合）、茅台（大额派息）、招行/平安（历史复杂除权含配股）等 7 只。

## 五、切换影响与注意事项

1. **日K缓存一次性清空**（v0.7.0 迁移），首次全市场扫描自动重建（一次性耗时较长）
2. 前复权后 B1/B2 等策略判定会与通达信前复权视图一致——历史命中记录中受除权影响的
   条目差异属**修正**，不是回归
3. `CachedFeed.get_daily_bars` 缓存命中时 `last_adjust="qfq"`（缓存即前复权口径）
4. 指数 K 线（`get_index_daily_bars`）无除权概念，不适用复权

## 六、DNA 二层精筛（依赖前复权）

- 模具制作与精筛比对**同源**（均为前复权），保证模具特征与候选特征口径一致
- 特征提取：先拉 300 天全序列计算黄白线（MA114 需 114 天预热），再截目标窗口
- 候选窗口末端锚定最新交易日；按模具长度对齐 + 长度弹性扫描（15~40天档位）
