# 策略版本归档 S0010 v1

- 策略编号：S0010（稳定不变，归集依据）
- 版本：v1
- 策略名称：B2类型标记(副图)
- 类型：指标存档
- 扫描节奏：manual
- 归档时间：2026-08-16 21:36:08

## 逻辑说明书

【类型】副图指标（信号标记）
【输出】B2类型数值：3 = 灾后重建（最强）/ 2 = 平行重炮 / 1 = 普通B2 / 0 = 无信号
【用法】复盘时在 K 线图上对照 B2 信号类型与形态，验证策略命中率。

## 公式原文

```
{ —— B2 三种类型标记（副图，输出 3/2/1/0） —— }
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
昨天B1:=REF(J,1)<13;
基础达标:=趋势好 AND 昨天B1 AND J>REF(J,1) AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1) AND J<55 AND J>13 AND C>黄线;
{ 平行重炮 }
重炮阳线:=(C>O) AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1);
炮收:=IF(重炮阳线,C,0);
炮高:=HHV(炮收,60);
炮低:=IF(炮高>0,LLV(IF(炮收>0,炮收,99999),60),99999);
炮次数:=COUNT(重炮阳线,60);
平行重炮:=基础达标 AND 炮次数>=2 AND (炮高-炮低)/炮低<0.1;
{ 灾后重建 }
金叉:=CROSS(白线,黄线);
金叉存在:=EXIST(金叉,30);
金叉日:=BARSLAST(金叉);
昨天黄线:=REF(黄线,1);
回踩黄线:=REF(C,1)/昨天黄线>=0.995;
建波均量:=REF(MA(V,5),金叉日);
回调区均量:=MA(V,5);
缩量达标:=回调区均量<建波均量*0.75;
灾后重建:=基础达标 AND 金叉存在 AND 回踩黄线 AND 缩量达标;
{ 普通 B2 }
普通B2:=基础达标 AND NOT(平行重炮) AND NOT(灾后重建);
{ 输出：3=重建 / 2=重炮 / 1=普通 / 0=无 }
B2类型:IF(灾后重建,3,IF(平行重炮,2,IF(普通B2,1,0)));
```
