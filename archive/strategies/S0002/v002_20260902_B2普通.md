## 逻辑说明书

【策略定位】B2 买点确认（B1 次日放量长阳，确定性中等）
【核心关系】B1 与 B2 是紧邻的两根 K 线：昨天 J<13（B1），今天放量长阳确认（B2）。
【七条核心条件】
  1. 昨天 J < 13（昨天是 B1）
  2. J 拐头向上（今天 J > 昨天 J）
  3. 涨幅 > 4%
  4. 放量（今天 V > 昨天 V）
  5. J < 55（不过热，不追高）
  6. J > 13（已脱离低迷区）
  7. 收盘价 > 黄线（站上主力成本；灾后重建场景自动满足）
【大前提】白线 > 黄线
【上影线分级】命中后结果中标注：完美 = 光头阳线（H=MAX(C,O)），稍欠 = 有上影
【已按你的要求移除】结构保护（大盘极端时允许破前低）
【可调参数】涨幅阈值 4%、J 上下界 13/55

## 公式原文

```
{ —— 通用前提 —— }
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
趋势好:=白线>黄线;
{ —— KDJ(9,3,3) —— }
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
{ —— B1 确认：昨天是 B1 —— }
昨天B1:=REF(J,1)<13;
{ —— B2 七条核心条件 —— }
条件1_J拐头:=J>REF(J,1);
条件2_涨幅:=100*(C-REF(C,1))/REF(C,1)>4;
条件3_放量:=V>REF(V,1);
条件4_J低温:=J<55;
条件6_J脱离:=J>13;
条件7_站上黄线:=C>黄线;
{ —— 基础达标 —— }
基础达标:=趋势好 AND 昨天B1 AND 条件1_J拐头 AND 条件2_涨幅 AND 条件3_放量 AND 条件4_J低温 AND 条件6_J脱离 AND 条件7_站上黄线;
{ —— 分级标注：完美=光头，稍欠=有上影 —— }
完美:基础达标 AND H=MAX(C,O);
稍欠:基础达标 AND NOT(H=MAX(C,O));
{ —— 信号输出 —— }
B2普通:基础达标;
```
