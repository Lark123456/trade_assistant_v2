# 个人股票交易决策辅助系统

围绕**个人交易策略**的完整闭环本地桌面应用：**盘前批量筛票 → 盘中重点范围自动扫描 + 观察池跟踪 + 提醒 → 盘后记录与复盘**。

数据层基于 **pytdx**（通达信行情服务器直连，秒级实时），界面 **PyQt5**，存储 **SQLite**。

> 数据源为公开行情服务器，仅供个人学习研究使用，请勿用于商业用途。

---

## 一、一天怎么用

| 时段 | 系统做什么 | 你做什么 |
|------|-----------|---------|
| **盘前** | 「扫描中心」跑**全市场批量扫描**（策略公式 + 完整日K指标判定，多线程并行） | 查看命中列表 → 观察池审核 |
| **盘中** | 每 1~5 分钟自动扫描**重点范围**（涨幅/成交额榜前列 + 观察池）；行情实时刷新；条件触发**提醒**（桌面弹窗+声音+微信推送） | 看提醒 → 审核新进票 → 操作时记录交易 |
| **盘后** | 全市场批量扫描；「当日总结」汇总新信号/提醒/观察池表现/当日交易 | 审核进池票、补理由、写决策日记、复盘 |

## 四、通达信公式语法

**数据序列**：`C/O/H/L/V/AMOUNT` + 指标列（`MA5/MACD_DIF/MACD_DEA/KDJ_K/KDJ_D/RSI6/BOLL_*/ATR14/VOL_MA5` 等）

**函数**：
- 均线类：`MA(x,N)` `EMA(x,N)` `WMA(x,N)` `SMA(x,N,M)` `DMA(x,A)` `SLOPE(x,N)`
- 周期类：`REF(x,N)` `HHV/LLV(x,N)` `SUM/STD(x,N)` `COUNT(cond,N)` `BARSLAST(cond)`
- 信号类：`CROSS(a,b)` `EXIST(cond,N)` `EVERY(cond,N)` `FILTER(cond,N)`
- 其他：`IF(cond,a,b)` `BETWEEN(x,lo,hi)` `ABS(x)` `MAX(a,b)` `MIN(a,b)`

**运算符**：`+ - * / > < >= <= = != AND OR NOT ( )`

**通达信脚本风格（v2）**：支持多语句、中文变量名、`{}` 注释、`:=` 赋值、
`名称:表达式;` 命名输出（最后一个输出作为信号，其余输出在扫描结果中作为标注）、
`REF` 第二参数为序列（如 `REF(MA(V,5), BARSLAST(金叉))`）。通达信公式基本可原样粘贴：

```
白线:=EMA(EMA(C,10),10);
黄线:=(MA(C,14)+MA(C,28)+MA(C,57)+MA(C,114))/4;
RSV:=(C-LLV(L,9))/(HHV(H,9)-LLV(L,9))*100;
K:=SMA(RSV,3,1);
D:=SMA(K,3,1);
J:=3*K-2*D;
{ 昨日 B1，今日 B2 确认 }
基础达标:=白线>黄线 AND REF(J,1)<13 AND J>REF(J,1)
          AND 100*(C-REF(C,1))/REF(C,1)>4 AND V>REF(V,1)
          AND J<55 AND J>13 AND C>黄线;
完美:基础达标 AND H=MAX(C,O);
稍欠:基础达标 AND NOT(H=MAX(C,O));
B2普通:基础达标;
```

**示例**：
```
MACD金叉:        CROSS(MACD_DIF, MACD_DEA)
放量上攻:        V > REF(V,1) * 1.5 AND C > O
突破平台:        C > REF(HHV(H,20),1) AND VOL_MA5 > REF(VOL_MA5,1)
金叉后首次回调:  FILTER(CROSS(MA(C,5),MA(C,10)), 3) AND C <= MA(C,5)
5日内MACD金叉:   EXIST(CROSS(MACD_DIF, MACD_DEA), 5)
```

## 四·二、通达信自选股同步（v0.8.2-8.4）

打通 Python 程序与本机通达信客户端的自选股板块，**双向导入导出**（手动触发）：

- **导出（Python → 通达信）**：把选出的票写入通达信自定义板块，在通达信里直接浏览 K 线、二次筛选
- **导入（通达信 → Python）**：读取通达信里筛好的板块，勾选后一键加入观察池（待审核，来源标注「通达信导入」）

**入口**：观察池顶部「🔄 通达信」按钮 + 行情日历三个子 Tab（一层粗筛/二层精筛/观察池）各自的「🔄 通达信」按钮（导出范围为当前筛选后的可见行）。

**导入目标分流（v0.8.5）**：
- **一级观察池大模块**打开 → 导入进一级观察池（watch_pool，待审核，原行为）
- **行情日历任一子 Tab** 打开 → 导入进**该日期的二级观察池**（`tdx_imports` 表，绑定当前查看的日历日期，仅在该日期日历的「观察池」子页显示，独立于一级观察池，可在该子页随时删除；如需转正式监控，可在该子页用「加入观察池」手动入一级池）

**实现**：
- `tdx_sync.py`：核心同步器。板块文件为 `<TDX>/T0002/blocknew/<名称>.blk`（纯文本，每行 `[市场位1位][6位代码]`+CRLF，市场位 0=深/1=沪/2=北交所）；板块注册 `blocknew.cfg`（每条 120 字节，GBK：名称 8 字节 + 类型 2 字节 + 保留 40 字节 + 文件名 70 字节）。板块名上限 4 个汉字（8 字节 GBK），超长自动截断。
- `ui/tdx_sync_dialog.py`：同步对话框。路径自动探测（`E:\TDX` 等常见路径）+ 手动浏览；导入前预览（代码/名称/市场/是否已在池），支持**全选/全不选/反选/仅显示未在池**（未在池默认勾选），按勾选导入；导出可选覆盖/追加。
- **注意**：导出后需重启通达信才能看到新板块；通达信运行中可能占用板块文件，写入失败会提示先关闭通达信。

**测试**：`test_tdx_sync.py`（核心模块 33 项，含真实 E:\TDX 只读验证）、`test_tdx_select.py`（导入勾选逻辑）。

## 四·三、保险机制（核对代码实现 == 你的本意）- **公式中文释义**：策略编辑器里输入公式时，右侧实时逐条翻译成人话
  （如 `白线>黄线` → “白线 大于 黄线”），保存前即可核对。
- **📖 说明书**：选中策略/指标查看「意图说明 + 逐条中文释义 + 公式原文」。
- **🔍 单票诊断**：选策略 + 输入股票代码，逐条展示每个中间变量的最新数值、
  每条条件的 ✅通过/❌不通过、最终信号结论与标注——可与通达信副图逐项对账。
  诊断结果顶部会标明**数据来源**（本地缓存 / 行情服务器 / 本地缓存但网络失败可能滞后），
  并支持勾选「强制刷新缓存」从服务器重新拉取；若服务器数据反而比本地缓存旧，
  系统会自动保留本地缓存，避免覆盖更新的数据。

## 五·一、选股流水线（v0.7.0：粗筛 → DNA精筛；v0.7.4：二层全自动串联；v0.8.0：业务层级与实现解耦）

```
策略 = level（业务层级）+ direction（选股方向）+ kind（技术实现：formula/indicator/dna）

一层粗筛 level=1（业务方向层）：策略公式 OR DNA形态判定
  → 命中按 direction 分组落库（layer=level）
  → 同 direction 同 level 可重叠（多策略命中同一票均落库）
        │
        ▼（v0.8.0：_chain_layerN(level, ...) 通用调度；v0.8.1：候选按 parent_strategy_ids 多选链式流转——
           level=N 的候选 = 其父策略（level=N-1）命中记录的去重合并，未指定父策略则取 level=N-1 全量命中）
二层精筛 level=2（业务精细层）：DTW骨架分 + 微观规则综合分
  - 候选窗口 = 模具长度对齐，末端锚定最新交易日（不滑动起点）
  - 长度弹性扫描 15~40 天取最高分（避免形态周期≠模具长度时漏选）
  - DTW Score = 100 × e^(−3.5 × 加权距离/路径长)，权重 价格0.5/量能0.3/均线0.2
  - 微观规则（core/micro_rules.py，11 条）加减分 ±20 + 买点定级
  - final_score = clip(dtw_score + score_modifier, 0, 100)
  - 过滤 final_score >= 75（或综合分 Top15）→ 持久化 layer=2：
    dtw_score/final_score/matched_template/buy_level/signals/direction
  - 命中自动进池：已在池则更新 DNA 标注 + level 升级，否则新增并标注来源
  - 全市场直测 = 快速模式（单档窗口）

跨层级不叠加：观察池 level 字段只升不降（精筛覆盖粗筛）
level=3+ 字段预留但调度代码留 TODO
```

## 六·一、择时模块（v0.8.8 极简版）

**两个巨大的 [📈 多头区间] / [📉 空头区间] 按钮各占一半屏幕。**点击点亮当前所处区间作为视觉提醒，选择持久化到 `settings` 表（key `timing.regime`，值 `bull` / `bear` / 空），程序重启后自动恢复。点击「清除选择」可回到未选状态。**无数据获取，无指标计算，纯个人判断留痕。**

配色与 A 股惯例一致：多头 = 红（涨 #e64340）/ 空头 = 绿（跌 #089981）/ 未选 = 灰。

> 历史：v0.8.6–v0.8.7 曾接入指南针「活跃市值」指标和三大指数自动监控，因数据源不可达 / 不符合「极简提醒」诉求而撤掉。`core.timing.judge` 判定函数仍可作为通用工具按需复用。

**扩展**：本模块刻意保持极简。如需加更多按钮（如"震荡"、"减仓"），在 `TimingTab.__init__` 中追加 `BigRegimeButton` + 信号即可。
