# 策略迁移与一键导出 / 导入（v0.10.5）

> 位置：**🎯 策略管理 → 「📤 导出策略」/「📥 导入策略」**
> 代码：`strategy_export.py`（打包/校验）、`database.py`（`export_*` / `import_strategy_bundle`）

---

## 一、策略到底存在哪里

| 位置 | 内容 | 是否进 git |
|---|---|---|
| `trade_assistant.db` → `strategies` 表 | 策略本体（公式/条件/层级/父策略/通达信简称/说明书） | ❌ 被 `.gitignore` 排除（`*.db`） |
| `trade_assistant.db` → `strategy_versions` 表 | 每个策略的历史版本 | ❌ 同上 |
| `archive/strategies/S00xx/*.md` | 每次改策略自动写的归档（**含逻辑说明书 + 公式原文**） | ❌ v0.10.5 起排除 |
| `dna_storage/` | 二层精筛的 DNA 模具库（npz + meta） | ✅ 已在仓库（属于程序资产） |
| `策略备份-*.json` | 一键导出的迁移包 | ❌ 排除 |

**结论**：策略配方只在本机数据库里。仓库里只有程序代码和内置预设（`strategy_presets.py`）。

## 二、一键导出

**策略管理 → 📤 导出策略** → 选保存位置（默认 `策略备份-YYYYMMDD.json`）。

导出内容：

| 区块 | 说明 |
|---|---|
| `strategies` | 全部策略：编号、名称、类型、公式、条件、说明书、层级、节奏、标签、通达信简称、父策略 |
| `strategy_versions` | 每个策略的历史版本（可追溯改动） |
| `dna_templates` | DNA 模具库（npz 转 base64 + meta），迁移后二层精筛直接用 |

**不导出**：行情缓存、扫描历史、观察池、交易记录，以及 settings 里的任何密钥
（飞书 App Secret / AI API Key 都不在文件里）。

单个文件，实测 13 个策略 + 33 条版本 + 10 个模具 ≈ 83 KB。

## 三、一键导入

**策略管理 → 📥 导入策略** → 选 JSON 文件 → 选择方式：

| 方式 | 行为 | 适用 |
|---|---|---|
| **合并导入**（推荐） | 按 `编号`（S0001）匹配：已存在则**更新**，不存在则**新增**；历史版本只补缺 | 日常同步、把旧机器策略搬到新机器 |
| **覆盖导入** | 先删除本地**全部**策略与历史版本，再按备份重建 | 全新机器 / 想完全还原某个时间点 |

两个关键细节：

1. **父策略引用会自动重映射**。层级串联靠的是数据库 id，换个库 id 必然不同，
   导入时会先建策略、再按 `旧id → 新id` 回填 `parent_strategy_ids`，
   所以「B1十张图 ← B1海选」这种父子关系不会断。
2. **DNA 模具库会被一并恢复**，旧文件自动备份成 `golden_templates.npz.bak-时间戳`。

## 四、换机器的完整步骤

```
旧机器：
  1. 策略管理 → 📤 导出策略 → 得到 策略备份-20261124.json
  2. 通过 U 盘 / 网盘 / 自己搭的私有渠道传到新机器（别传公开仓库）

新机器：
  1. 拉代码：git clone https://github.com/Lark123456/trade_assistant_v2.git
  2. 装依赖：pip install -r requirements.txt
  3. 首次启动 main.py（会自动建空库 trade_assistant.db）
  4. 策略管理 → 📥 导入策略 → 选那个 JSON → 合并导入
  5. 重启程序（模具库与策略列表刷新）
  6. 按需重新配置：飞书 Webhook / App ID / AI Key（这些**不在**备份里）
```

> 行情缓存不需要迁移，扫描时会自动重新拉取。

---

## 五、注意事项

- **导出文件 = 你的策略配方**，等同于源码资产，不要放进公开仓库、不要发到群里。
  `.gitignore` 已拦截 `策略备份-*.json`，但仍建议存到项目目录之外。
- 回测统计（胜率/盈亏比）**不迁移**——那是本地历史推出来的，换机器没有意义。
- 覆盖导入不可撤销；如果这台机器上有备份里没有的策略，会一并丢失。
  建议覆盖前先自己导出一份当前状态。
- 导入后如果界面没变，点一次「刷新」。
